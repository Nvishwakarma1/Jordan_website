# Luxury Interior Architecture & Design Studio

A luxury interior design and architectural studio web application featuring an interactive 3D frame-scroll canvas sequence, project showcases, cost estimator, customer reviews, and a responsive modern interface.

## Tech Stack

- **React 18**
- **Vite**
- **Framer Motion**
- **Tailwind CSS / PostCSS**
- **React Icons**

## Getting Started

### Prerequisites

- Node.js (version 18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Nvishwakarma1/Jordan_website.git

# Navigate into the project folder
cd Jordan_website

# Install dependencies
npm install

# Start the local development server
npm run dev
```

### Building for Production

```bash
npm run build
```

## Features

- **Interactive 3D Canvas Scroll**: Seamless frame-by-frame animation on scroll for immersive presentation.
- **Project Portfolio**: Categorized interior design showcases with interactive views.
- **Cost Estimation Tool**: Interactive estimator for custom design consultations.
- **Dark/Light Luxury Theme**: High-contrast, tailored visual aesthetics.
